# H1 cost analysis

This artifact records arithmetic from `npm run estimate`; it contains no
benchmark measurements and does not infer ChatGPT quota consumption. The dollar
figures are hypothetical standard API-price calculations. A ChatGPT plan's
quota accounting is separate from API billing, so these values are not claims
about future savings.

The generated scenarios use context `N = 300,000`, post-shake `N' = 120,000`,
post-compaction context `30,000`, 3,000 input tokens per turn, 1,000 generated
output tokens per ordinary turn, 2,000 compaction output tokens, and 768 tokens
per recovery page. Recovery call output is 100 tokens. Warm means the existing
context is cached before the first request; cold means it is not. The model
adds input tokens before each request, appends generated output after that
request, and charges the generated output as uncached input on the next request.
For recovery, each tool-call output and page is appended before its continuation;
the final answer output occurs on the last continuation.

The estimator models recovery reads as serial continuations. The shipped runtime
can batch multiple nested tool calls inside one outer code-mode continuation, so
observed nested attempt counts must be compared with usage updates and request
boundaries before treating them as billed request counts.

## Published rates

The table below is the generated `pricing.json` table, fetched 2026-09-10.
Rates are USD per million tokens.

| Model | Input | Cached input | Cache write | Output | Long-context multipliers (input/cache/write/output) |
|---|---:|---:|---:|---:|---|
| `gpt-6-astra` | 10 | 1 | 12.5 | 50 | 2x / 2x / 2x / 1.5x |
| `gpt-5.6-sol` | 4 | 0.4 | 5 | 20 | 2x / 2x / 2x / 1.5x |
| `gpt-5.6-terra` | 2 | 0.2 | 2.5 | 12 | 2x / 2x / 2x / 1.5x |
| `gpt-5.6-luna` | 0.2 | 0.02 | 0.25 | 1.2 | 2x / 2x / 2x / 1.5x |

The Astra page explicitly states 2x input and cache rates plus 1.5x output for
requests above 272K. The GPT-5.6 pages state 2x input and 1.5x output above
272K; the cache read and write multipliers follow the official prompt-caching
ratios applied to the applicable uncached input rate. Cache writes are 1.25x
the uncached input rate.

Sources: [GPT-6 Astra](https://developers.openai.com/api/docs/models/gpt-6-astra),
[GPT-5.6 Sol](https://developers.openai.com/api/docs/models/gpt-5.6-sol),
[GPT-5.6 Terra](https://developers.openai.com/api/docs/models/gpt-5.6-terra),
[GPT-5.6 Luna](https://developers.openai.com/api/docs/models/gpt-5.6-luna),
and the [prompt-caching guide](https://developers.openai.com/api/docs/guides/prompt-caching).

## Serial-read sensitivity

This is Astra, warm cache, `T = 20`, with the same canonical context and token
assumptions. Only the number of serial recovery reads changes.

| Recovery reads | No shake | Shake | Compact | Shake then compact | Shake break-even |

| 0 | $16.9570 | $6.5085 | $4.4235 | $5.2735 | 3 |
| 3 | $16.9570 | $6.9771 | $4.4235 | $5.4721 | 4 |
| 15 | $16.9570 | $8.9298 | $4.4235 | $6.3448 | 7 |

The read counts here are deliberately chosen sensitivities. They are not
measured `read_artifact` counts from a completed benchmark, and the serial
model should not be applied directly to batched runtime attempts.

## Original no-multiplier hypothesis

`--hypothetical-no-long-multiplier` sets all long-context multipliers to 1 and
prints a clearly labeled hypothetical. It does not alter the published pricing
table. Astra warm, no recovery reads, `T = 1/5/20` produces:

| T | No shake | Shake | Compact | Shake then compact | Shake break-even |
|---:|---:|---:|---:|---:|---:|
| 1 | $0.3875 | $1.5875 | $0.8625 | $2.0625 | 8 |
| 5 | $2.0235 | $2.5035 | $1.4185 | $2.6185 | 8 |
| 20 | $8.7285 | $6.5085 | $4.0735 | $5.2735 | 8 |

## Reproduce

Run from the repository root:

```bash
npm run estimate
npm run estimate -- --model gpt-6-astra --context 300000 --post-shake 120000 \
  --post-compact 30000 --turns 20 --per-turn 3000 --output-per-turn 1000 \
  --compaction-output 2000 --reads 0 --cache warm
npm run estimate -- --model gpt-6-astra --context 300000 --post-shake 120000 \
  --post-compact 30000 --turns 20 --per-turn 3000 --output-per-turn 1000 \
  --compaction-output 2000 --reads 15 --recovery-tokens-per-read 768 \
  --recovery-output 100 --cache warm
npm run estimate -- --model gpt-6-astra --context 300000 --post-shake 120000 \
  --hypothetical-no-long-multiplier
```
