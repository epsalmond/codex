Test builds of the `eric/local-features` branch.

**Shake** cuts old tool output, images, or thinking from a Codex thread. Each cut is saved to a file under `$CODEX_HOME/artifacts/` and the placeholder names the path.

**Auto-shake** is on by default: 160k tokens on gpt-5.6, 40% of the window on Astra, and on any resume after the prompt cache has expired.

- Docs and config: [shake.md](codex-rs/docs/shake.md)
- Benchmark scripts and full reports: [shake-bench](codex-rs/docs/shake-bench/README.md)
